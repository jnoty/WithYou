# 任务看板 — 基本需求文档（PRD）

- 版本：v0.1
- 状态：草案
- 范围：最小可用版本（MVP）

---

## 1. 产品概述

### 1.1 产品定位

一款类似「小黄条」的轻量级桌面任务看板工具：便签卡片 + 看板视图 + 桌面常驻。核心是让用户在 3 秒内记下一件事，一屏之内看清所有事。

### 1.2 目标用户

- 个人轻量任务管理用户（学生、自由职业者、普通办公人群）
- 不需要复杂项目管理，只需要"记下来、看到、做完"

### 1.3 设计原则

1. **捕获成本趋近于零**：新建一条任务 ≤ 3 秒
2. **一屏全局**：打开即见所有事，不做深导航
3. **状态可见**：在做什么、什么逾期、什么做完，一眼分清
4. **数据永远不丢**：自动保存、可撤销、可导出

## 2. 功能需求

优先级定义：P0 = 必须有（没有则产品不成立）；P1 = 应该有（影响体验）；P2 = 可以有（二期）。

### 2.1 任务管理（P0）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-101 | 快速新建任务 | 单输入框 + 回车即建，仅标题必填，无弹窗表单 |
| F-102 | 编辑任务 | 就地编辑标题和备注，双击进入编辑 |
| F-103 | 完成/取消完成 | 点击勾选切换状态，完成后置入"已完成"列 |
| F-104 | 删除任务 | 删除后支持撤销（Toast 提示 + 撤销按钮） |
| F-105 | 拖拽排序 | 同列内拖拽排序、跨列拖拽换状态 |
| F-106 | 完整添加任务 | 弹窗表单填写任务名（必填）/ 任务内容 / 开始时间 / 结束时间 |
| F-107 | 重复任务 | 每天 / 每周 / 每月 + 重复截止日期，一键生成时间段内的多次任务（展开为独立任务，单次 ≤ 200 条） |

### 2.2 看板视图（P0）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-201 | 三列默认状态 | 待办 / 进行中 / 已完成 |
| F-202 | 已完成折叠 | 已完成列默认折叠，按完成日期倒序，可展开 |
| F-203 | 卡片信息展示 | 标题、备注摘要、截止日期、颜色标记、逾期标识 |

### 2.3 便签卡片（P0）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-301 | 颜色标记 | 6~8 种预设颜色，用于区分类别或优先级 |
| F-302 | 备注 | 单条任务附带简短纯文本备注（≤ 500 字） |

### 2.4 数据持久化（P0）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-401 | 本地自动保存 | 所有变更即时落盘，异常退出/断电后重启数据不丢失 |
| F-402 | 导出 | 导出为 JSON 文件 |
| F-403 | 导入 | 从 JSON 文件恢复数据 |

### 2.5 时间与提醒（P0）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-501 | 截止日期 | 可为任务设置日期（精确到分钟） |
| F-502 | 系统通知 | 到点弹出系统通知提醒 |
| F-503 | 逾期高亮 | 逾期任务卡片变红并置顶显示 |

### 2.6 快速捕获（P1）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-601 | 全局热键 | 全局快捷键唤起速记小窗，随手建一条 |
| F-602 | 托盘常驻 | 主窗口可最小化到系统托盘，托盘菜单可快速新建/打开 |

### 2.7 搜索与筛选（P1）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-701 | 关键词搜索 | 按标题、备注搜索 |
| F-702 | 筛选 | 按颜色、截止日期（今日/本周/逾期）筛选 |

### 2.8 桌面形态（P1）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-801 | 窗口置顶 | 可设置窗口始终置顶 |
| F-802 | 外观设置 | 透明度、圆角等轻量设置 |
| F-803 | 开机自启 | 可选开关，默认关闭 |

### 2.9 桌面宠物（P1）

| 编号 | 需求 | 说明 |
|------|------|------|
| F-901 | 桌宠呈现 | 独立透明置顶小窗、不占任务栏；插画形象（assets/pet-cat.png），待机呼吸/摇摆/睡觉动画 |
| F-902 | 基础互动 | 单击抚摸、双击喂食、右键菜单（打开主窗/速记/喂食/设置/隐藏桌宠） |
| F-903 | 任务联动 | 新建/完成任务有气泡反馈（完成触发庆祝动画）；到期/逾期气泡提醒；有逾期任务时心情变差 |
| F-904 | 拖拽与位置记忆 | 可拖动；贴近屏幕边缘自动吸附（可关）；重启后记住位置，越界自动钳回可见区 |
| F-905 | 轻养成 | 心情 / 经验 / 等级 / 喂食冷却（4 小时）；心情随闲置衰减；23:00–7:00 进入睡觉动画 |
| F-906 | 桌宠设置 | 显示开关 / 大小（80%–150%）/ 气泡提醒开关 / 贴边吸附开关；托盘菜单可显示/隐藏 |

### 2.10 明确不做（本期范围外）

- 账号体系、云同步、多人协作
- 子任务嵌套（超过两层的任务结构）
- 甘特图、工时统计（重复任务已支持：按规则批量展开为独立任务）
- 移动端 / 网页端
- 桌宠换装 / 背包 / 多宠物等重养成玩法

## 3. 数据模型（建议）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识 |
| title | string | 是 | 标题，≤ 100 字 |
| note | string | 否 | 备注，≤ 500 字 |
| status | enum | 是 | todo / doing / done |
| color | string | 否 | 颜色标记，默认无色 |
| startAt | datetime | 否 | 开始时间；没有截止时间时作为提醒时间 |
| dueAt | datetime | 否 | 截止（结束）时间，默认提醒时间 |
| reminderAt | datetime | 否 | 独立提醒时间，优先于截止/开始时间 |
| reminderDisabled | boolean | 否 | 关闭此任务的提醒 |
| seriesId | string | 否 | 重复任务系列标识，用于按系列改期 |
| sortOrder | number | 是 | 列内排序权重 |
| createdAt | datetime | 是 | 创建时间 |
| updatedAt | datetime | 是 | 更新时间 |
| completedAt | datetime | 否 | 完成时间 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 启动时间 ≤ 2 秒；500 条任务内拖拽、搜索无卡顿 |
| 可靠性 | 自动保存间隔 ≤ 1 秒；崩溃后重启数据完整 |
| 兼容性 | Windows 10/11 优先，分辨率 1280×720 起适配 |
| 易用性 | 新建任务 ≤ 3 秒；常用操作（新建/完成/删除）不超过 2 步 |
| 数据安全 | 数据存本地，导出文件不依赖云服务 |

## 5. 验收标准（MVP 验收清单）

1. 可以在主界面输入框回车创建任务，卡片即时出现在"待办"列
2. 可以拖拽卡片在列内排序、跨列移动
3. 双击卡片可编辑标题和备注
4. 点击勾选后任务移入"已完成"列，再次点击可恢复
5. 删除任务后 5 秒内可通过撤销恢复
6. 设置截止时间并到期后，系统弹出通知；逾期任务红色高亮并置顶
7. 任务可标颜色，并按颜色筛选
8. 强制结束进程后重启，数据与退出前一致
9. 导出 JSON 后清空数据再导入，数据完整恢复
10. 全局热键可唤起速记窗（P1 验收项）
11. 桌宠可拖动贴边、重启后位置保持；完成任务触发庆祝动画，到期任务有气泡提醒（P1 验收项）
