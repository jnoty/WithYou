# 携手 WithYou 页面与功能评估

日期：2026-11-06。仅评估并生成报告，没有修改业务代码。

## 检查方法与范围

使用独立临时数据和模拟模型渲染实际 Electron 页面，检查列表、日历、项目资料、AI 输入、手动添加、AI 预览与详情、模型配置、优先级、桌宠设置、备份设置，以及 760×600 窗口下的模型设置。检查快速添加跨窗口流程、提醒、默认模型、重复任务、导入导出、桌宠逻辑源代码。没有在用户真实任务上执行增删，没有调用真实付费模型。

限制：本次不是全部功能的端到端验收。托盘、操作系统通知、真实网络、桌宠动作、多显示器及全部缩放比例未逐项实测。模拟模型截图中的任务内容用于布局检查，不用于判断真实模型准确率。MoliTodo 对照基于官方公开仓库与官网，未安装运行对方应用。

## 总体判断

品牌配色、卡片风格、设置分组和 AI 确认机制已有较好基础。主要问题是新功能接入后缺少统一的时间语义、草稿状态和配置流程；部分说明与实际行为不同。先完善记录—识别—核对—保存—提醒这一条主流程，再增加功能。

P0：可能漏提醒或丢失未保存内容；P1：影响高频操作或容易误解；P2：可后续优化。

| P1 | 首页信息结构 | 1180×760 截图中任务内容从较低位置开始，问候、完成率、长进度条、视图栏、状态栏、展开筛选占据大量高度；列表首屏只能看少量任务。 | 缩小问候区，完成率保留一个表达；默认折叠筛选；卡片按内容压缩高度，子任务默认显示进度。验收用短任务和长任务混合列表测首屏信息量。 |

| P2 | 项目资料 | 本质是按项目名分组的链接/路径收藏，与任务没有直接关联；资料页仍展示全局任务完成率。 | 先明确为“项目资料/快捷入口”；可选关联任务或项目。资料页移除不相关的任务统计，增加缺失文件路径提示。 |
| P2 | 桌宠与通知 | 居中奔跑动画与气泡提醒绑定，只有预览按钮，没有独立强度开关；动作库在普通设置占据显著位置。 | 分离系统通知、桌宠气泡、居中动画；增加安静模式。动作库放入外观高级设置，保留陪伴特色。 |
| P2 | 通用外观与可访问性 | 整体颜色统一，但较多小字号辅助文字和弱对比按钮；有透明度和圆角配置，缺少字体大小、主题等更直接的阅读选项。 | 优先提供字体大小、跟随系统主题、减少动态效果；确认键盘焦点、Tab顺序、125%/150%缩放和长模型名布局。当前仅作视觉评估，未做对比度标准测量。 |

## MoliTodo 对照与取舍

参考：[官方仓库](https://github.com/gusibi/MoliTodo)、[官网功能说明](https://molitodo.eztoolab.com/en/)。以下是对其公开功能的概括，不代表实际安装体验评分。

MoliTodo 强调悬浮入口的快速访问、AI 流式生成及创建前预览编辑，提供日/周/月日历、独立列表与状态看板、重复系列及实例覆盖。可借鉴其入口职责清楚、视图名称与内容匹配、重复任务有系列语义的设计。

携手应保留：AI 默认识别、统一可编辑确认、快捷窗口、桌宠陪伴、本地数据与整批撤销。继续复用同一确认组件，不增加第二套简化预览。当前月历和列表做扎实之后，再考虑周视图；工作报告、计时、统计热力图、开放API等不宜一起引入。

## 建议实施顺序

第一批：会议提醒闭环、开始时间常驻预览、草稿恢复、筛选状态修复、模型连接实测及配置未保存保护。

第二批：顶部压缩、列表命名与编辑入口、日历排期、全局默认模型统一、空状态和错误恢复路径。

第三批：重复系列、完整备份、资料关联、优先级简化和桌宠通知强度。
