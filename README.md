# 携手 WithYou｜与你一起记录生活和工作

一款轻量桌面记事工具：**便签卡片 + 看板视图 + 桌面常驻**，陪你一起记录生活与工作的点滴。
核心体验：3 秒内记下一件事，一屏之内看清所有事。

技术栈：Electron + 原生 HTML/CSS/JS（无构建步骤），数据本地 JSON 存储。

## 关联项目

`C:\WithYouWeb\app` 是携手（WithYou）的关联网页项目，采用 React + TypeScript + Vite；本仓库是 Electron 桌面应用。两者共享产品名称、品牌和整体体验方向，但代码、依赖、构建与发布流程分别维护。涉及品牌或跨端体验的改动时，可参考并协调另一项目；不要假设两边共享实现或数据存储。

## 快速开始

```bash
npm install     # 安装 Electron（国内网络可加镜像：ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/）
npm start       # 启动应用
npm test        # 数据层单元测试
```

## 界面风格

界面沿用携手介绍网页的浅薄荷背景、森林绿与金黄色点缀，采用更简洁的工具栏、轻量任务卡片和统一圆角按钮。时间与优先级筛选默认收起，点击「筛选」展开；收起后仍显示已选条件，可展开后一键清除。任务列表采用与网页一致的统一列表，通过「全部 / 待完成 / 已完成 / 已取消」四个标签筛选，不再按状态分栏；另保留日历视图。速记窗口和桌宠提醒气泡使用相同配色。

顶部完成率按全部非取消任务计算（已完成 / 待办、进行中与已完成总数），不随搜索、时间或优先级筛选变化；没有任务时显示 0%。

启动后即可看到新版界面，无需前端构建。已打包的旧版本需重新运行 `npm run dist` 才会包含这些改动。

可运行 `npx electron tools/ui-smoke.js` 检查完成率、新建与编辑、日历、弹窗和最小窗口布局。验证使用独立临时数据，不读写真实任务，截图目录会输出到终端。

|------|------|

| F-902 基础互动 | 单击抚摸（爱心特效）、双击喂食（🍰 + 咀嚼动画）、右键菜单（打开主窗 / 速记 / 喂食 / 设置 / 隐藏桌宠） |
| F-903 任务联动 | 新建 / 完成任务气泡反馈（完成触发庆祝动画），到期 / 逾期气泡提醒，有逾期任务时心情变差 |
| F-904 拖拽与位置记忆 | 拖动（<5px 视为点击）；贴屏幕边缘 12px 内，动画躲入对应侧的左下 / 右下桌角，仅探头；悬停跑出坐下，移开 1.2 秒后再次躲藏（可关）；重启记住桌角位置 |
| F-905 轻养成 | 心情 0~100 / 经验 / 等级（级差 100 递增）/ 喂食冷却 4 小时；闲置每小时 -2 心情；23:00–7:00 睡觉（可点击唤醒 5 分钟） |

宠物大小按裁去透明留白后的猫身显示比例计算；静态素材使用 `assets/pet-cat-trimmed.png`，两组动作采用同一素材缩放比例。鼠标仅在猫的可见轮廓、状态条或提醒气泡上被捕获，外围透明区域可直接点击桌面。原始素材保留，运行 `node node_modules/electron/cli.js tools/pack-pet-sprites.js` 可重新生成裁切素材与动作条。

猫咪动作库包括奔跑、跳跃、躲进桌角、探头待机、跑出来坐下五组独立制作的逐帧素材，每组 8 帧。新增桌角素材分别存放于 `assets/pet-hide/`、`assets/pet-peek/`、`assets/pet-emerge/`，同时提供透明精灵条和 APNG 动画预览。在「设置 → 桌面宠物 → 查看动作动画」中可单独预览，也可直接打开 `src/renderer/pet-animation-preview.html`。生成提示词见 `assets/pet-animation-prompts.md`。

贴边躲藏使用独立状态机：640 ms 躲进桌角 → 1920 ms 探头循环 → 悬停时用 800 ms 跑出坐下；鼠标离开猫身后等待 1.2 秒再收起。透明区域仍可点穿，状态条和气泡在躲藏时隐藏。任务到期会临时唤出桌宠完成居中提醒，结束后恢复桌角状态；开始拖动、关闭桌宠或关闭贴边吸附会取消当前躲藏。可运行 `node node_modules/electron/cli.js tools/pet-dock-smoke.js` 验证完整流程，测试使用独立临时数据。

## 数据存储位置

### AI 整理任务

AI 输入和确认界面参考 MoliTodo 的任务列表式预览进行了精简：输入页以文本框为主，统一使用设置中的默认模型；确认页默认展示勾选框、可编辑标题和负责人／时间／子任务数量摘要，其余字段与原文引用收进「编辑详情」。可从预览列表移除任务，筛选及会议结论按需展开；待确认事项和 AI 建议保持可见。创建仍需用户显式确认。

模型设置界面参考 DeepSeek Harness 的供应商列表与单卡片编辑结构：已保存的供应商以卡片展示名称、协议、模型数量及密钥保存状态（不表示联网验证成功）；点击编辑展开配置，取消放弃编辑，保存后收起。「自定义设置」集中放置协议、接口及模型目录。获取模型后可搜索并多选，再点击「添加所选模型」批量加入草稿，保存供应商后生效。

模型配置按「供应商 → 多个模型」管理。在「设置 → AI 与模型」选择或添加供应商，分别填写名称、API 格式、地址和密钥；通过「手动添加模型」或模型检测结果添加多个模型，模型标签上的 × 可移除该模型，点击「保存连接设置」生效。供应商支持编辑和删除，删除不会影响已有任务。每个供应商的密钥独立加密保存，不会跨供应商复用。旧的单供应商／单模型配置首次加载时自动迁移。

「新任务」、快速添加和重新整理统一使用设置中的全局默认模型，输入和结果页面不再选择供应商或模型。

Responses 格式支持基础地址或完整的 `/responses` 地址，采用 Bearer 认证，以 `instructions`、`input` 和 `text.format` 请求 JSON 输出；从 `output` 中提取助手文本块。仅接受完整响应，截断、失败和拒绝响应不会创建任务。请求设置 `store: false`，不使用服务端会话续接。模型检测仍查询同一前缀下的 `/models`。任务创建、预览、来源保存和整批撤销流程与其他格式一致。

「新任务」默认提供「AI 输入」：粘贴工作描述或会议记录后点击「AI 整理」，生成草稿并自动弹出预览，复用同一次整理结果，不重复调用模型。此时尚未创建任务；在预览中编辑、勾选所需任务，再点击「确认并创建任务」才批量保存。关闭预览不会创建任务，原文会保留。AI 建议默认不勾选，可核实后选中；成功创建后可整批撤销。普通回车换行，Ctrl/Cmd + Enter 整理。接口失败保留输入，也可切换「手动填写」。不再单独提供「预览整理」按钮。模型连接统一在「设置 → AI 与模型」中配置。

点击齿轮「设置 → AI 与模型」，在「API 格式」下拉框选择 OpenAI 兼容（Chat Completions）、OpenAI 兼容（Responses）或 Anthropic 兼容（Messages），填写接口地址、模型名称与个人 API Key，然后点击「保存连接设置」。旧配置默认采用 OpenAI 兼容格式。支持基础地址（如 `https://your-provider.example/v1`）和完整接口地址，程序会按所选格式使用 `/chat/completions`、`/responses` 或 `/messages`；只有域名时默认补 `/v1`。OpenAI 格式使用 Bearer 认证和 JSON 模式，Anthropic 格式使用 `x-api-key`、`anthropic-version: 2023-06-01`、独立 system 字段及 `max_tokens`，从响应文本块解析任务 JSON。设置采用分类导航，内容区域独立滚动，底部「完成」按钮常驻。本机接口允许 HTTP，无需鉴权时可留空密钥；远程接口须使用 HTTPS。密钥通过系统凭据加密，保存在 `ai-config.json`，不会放入任务导出文件。

无需选择整理模式，直接粘贴最多 30000 字原文，AI 自动识别工作描述、会议纪要或混合内容。工作描述可补充建议步骤；会议内容提取明确行动项，将讨论、否决与暂不执行的事项单独展示；无法判断时采用保守提取。模型结果仍需核对，尤其是相对日期与任务归属；未明确的具体时刻不自动补齐。AI 补充建议和无法匹配原文的内容默认不勾选，确认后才创建任务。

「设置 → AI 与模型」中的「检测并获取模型」会使用当前选择的 API 格式、接口和 Key（Key 留空时使用已保存的密钥），查询同一路径前缀下的 `/models`。Anthropic 列表支持按游标继续读取分页。选择返回的模型会填入模型名称，再点击「保存连接设置」生效。切换格式或修改连接信息会清除旧列表。获取列表不会保存配置或发送任务内容；服务不支持模型列表时仍可手动填写。返回列表表示服务公布的模型，不保证每个模型都能用于任务整理或当前账户具有调用额度。

预览中可修改标题、项目、备注、负责人、依赖、日期和子任务；可直接输入项目名称或选择现有项目。填写自己的姓名后可按负责人精确匹配「只看我的任务」，未指定负责人的任务在「全部行动项」里查看。只创建当前显示且勾选的任务，负责人、依赖和待确认事项写入备注。批量创建最多 50 个任务，一次保存；重复提交同一草稿不会重复创建。

完整原文与任务关联保存在 `tasks.json` 的 `sources` 集合，随任务备份导出、导入和重启保留。点击任务卡片「查看原文」或整理面板「来源记录」回看。面板内可撤销本次会话最后创建的一批任务（包括后续编辑），删除前会确认。仅点击整理时才将本次原文发送到所配置的服务，不发送现有任务库；普通记事不依赖模型服务。

运行 `node test/ai.test.js` 验证提取校验、批量保存、来源备份、重复提交、失败回滚与取消；运行 `node node_modules/electron/cli.js tools/ai-smoke.js` 验证真实界面。测试使用独立临时目录和模拟模型，不读取真实任务，不调用付费模型。真实模型的提取质量需要配置接口后进一步验证。

| 内容 | 位置 |
|------|------|
| 任务数据 | `%APPDATA%\WithYou\tasks.json` |
| 设置 | `%APPDATA%\WithYou\settings.json` |
| 桌宠状态 | `%APPDATA%\WithYou\pet.json` |

## 设计说明

- **数据永远不丢**：所有变更立即落盘（原子写入，Windows 下对占用冲突做有限重试）；删除默认进入「可撤销」流程（5 秒窗口）
- **重复任务 = 批量展开**：按每天 / 每周 / 每月在日期范围内展开为独立任务（一次落盘），单条编辑 / 删除互不影响
- **提醒去重**：`notifiedAt` 标记已通知的任务。实际提醒时间改变后重置，允许再次提醒。
- **崩溃恢复**：`tasks.json.tmp` + `rename` 保证任一时刻数据文件完整可读
- **桌宠状态单一来源**：心情 / 经验 / 等级等养成状态由主进程统一计算（`src/pet-behavior.js` 纯函数，可单测），渲染层只负责动画与气泡；`pet.json` 同样采用原子写 + 防抖落盘
- **性能**：500 条任务内拖拽、搜索为纯内存操作，无卡顿

### 套餐接口与错误诊断

OpenCode 请求使用真实的 `WithYou/<版本>` User-Agent，并携带 `x-opencode-session` 会话标识。Kimi Coding 基础地址 `https://api.kimi.com/coding/`（或 `api.kimi.ai`）会自动补齐 `/v1`，再按所选 API 格式拼接路径。套餐仍受供应商账户权限、客户端与用途限制；应用不会伪装成其他编码客户端。

模型请求失败时显示 HTTP 状态和服务端 JSON 错误类型、原因；错误详情会隐藏当前 Key 和完整输入，并限制长度。生成请求的失败记录保存在应用数据目录 `ai-errors.log`（Windows：`%APPDATA%/WithYou/ai-errors.log`），超过约 256 KB 后重置。不记录请求头、请求正文或成功输出。

快速新建（Ctrl+Alt+N）默认使用已保存的默认 AI 模型识别任务与自然语言时间，先预览再确认创建。例如“明天下午三点参加会议”按当前用户时区与参考日期解释，会议时间填开始时间，未提供结束时间则不推测时长。修改原文可重新识别；未配置模型或请求失败时保留输入，可选择普通创建。普通创建最多保存 1200 字，前 200 字作为标题，其余保存为备注。

设置 → AI 与模型 → 全局默认模型可独立选择供应商及模型并自动保存。快速添加和 AI 整理统一使用此默认值；保存其他供应商不会切换全局默认。删除默认供应商或移除默认模型后，自动采用剩余可用配置。快速添加窗口可调用识别和确认创建，不能修改模型连接设置。

快速新建完成 AI 分析后，会唤起主窗口并打开与 AI 整理相同的可编辑结果弹窗。可修改任务标题、时间和详情，勾选后确认创建；关闭弹窗不会创建任务。主窗口已有结果弹窗时，新预览会等待其关闭。

任务和项目资料均按项目分组，点击项目标题可折叠或展开，状态保存在本机。任务可在新建、编辑或 AI 确认时归入已有项目，留空时归入「未分类」。资料项目标题旁的「添加资料」会自动带入该项目；顶部添加入口可选择已有项目，或选择「新建项目」输入名称。资料可为同一名称保存多条路径或链接，每行一条，点击地址即可打开；选择本机路径会追加到地址列表。编辑未保存内容时关闭会先确认。

页面确认与信息提示使用统一的页面内弹窗，取消后恢复原焦点。设置关闭、按 Esc 和点击遮罩统一执行一次未保存检查。快速添加的普通创建与项目资料保存期间会锁定表单，失败后恢复可编辑状态；项目资料保存期间不能关闭或重开表单，避免旧请求关闭新表单。

已移除独立的全天日期功能。新任务、编辑和 AI 预览统一使用开始时间、截止时间及可选提醒时间。仅有日期但缺少具体时刻的 AI 输入会保留在待确认事项，不自动补充时间。旧任务和未确认草稿的 dateAt 会转为备注中的“原日期”，不再触发默认 09:00 提醒。

提醒支持提前 5、10 或 30 分钟，默认提前 5 分钟。优先按开始时间计算，仅填写截止时间时按截止时间计算。未设置起止时间的普通任务不会触发提醒。新增、编辑和 AI 确认使用同一组选项，改期后自动重新计算。旧的自定义提醒保留兼容，编辑保存后采用所选提前量。

AI 模型统一在「设置 → AI 与模型 → 全局默认模型」管理。新增任务、快速添加、重新整理和恢复草稿后的重新分析均使用当前默认模型，输入及确认页面不再提供单次模型选择。更改默认模型不会重新分析或修改已经创建的任务。

在项目资料卡片上直接点击地址。网页链接会在浏览器打开，文件夹会直接打开，本地文件会在资源管理器中定位并选中。

项目资料卡片使用与任务列表协调的配色、字体、间距和悬停效果，保留项目分组。卡片只显示定位/打开与垃圾桶图标；编辑、复制和删除可通过右键菜单操作，也支持 Shift+F10 打开菜单。删除直接执行，并可撤销。

待确认草稿入口位于新增任务弹窗，有未确认草稿时显示，可恢复原文及编辑结果。主界面不再单独显示草稿按钮。任务原文只读，支持选中文字复制与复制全文。资料操作按钮显示为“打开”，垃圾桶位于卡片右上角，删除后可撤销。

整理选项仅保留参考日期和记录名称，不再提供模型连接设置跳转；模型管理入口统一为主界面设置中的「AI 与模型」。

任务确认页使用「返回」按钮，返回前保存草稿修改并恢复新增任务弹窗。由待确认草稿进入时保留新增弹窗原有输入；创建成功仍关闭弹窗回到任务列表。「查看原文」保持只读，使用「关闭」回到列表。
